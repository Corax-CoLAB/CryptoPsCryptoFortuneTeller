# Security Policy

## Supported Versions

Currently, the `main` branch is actively supported with security updates. We recommend always running the latest version from `main`.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them by opening a GitHub Security Advisory or reaching out to the maintainers privately if possible.

If you find a vulnerability, we ask that you:

*   Provide detailed steps to reproduce the issue.
*   Describe the impact of the vulnerability.
*   Allow us a reasonable amount of time to fix the issue before making it public.

We will try to acknowledge your report within 48 hours and provide updates as we work on a fix.
